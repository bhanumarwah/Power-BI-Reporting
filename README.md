# Power-BI-Reporting
This repository contains interactive Power BI dashboards developed using real-world business datasets. The dashboards demonstrate data modeling, Power Query transformations, DAX calculations, and interactive report design to support business decision-making.

The projects focus on transforming raw data into meaningful insights through visually compelling and user-friendly dashboard

Analyze sales performance across products, customers, and regions to identify business growth opportunities.

#### Key Business Metrics
Total Sales
Profit
Orders
Quantity Sold
Profit Margin
Sales Growth

#### Dashboard Features
Executive Summary
Sales Trend Analysis

## Dashboard 2 – Hospitality Analytics Dashboard
### Project Objective
Develop an executive dashboard to monitor the performance of a hospitality business by analyzing bookings, occupancy, revenue, and customer trends.

#### Key Business Metrics
Revenue
Occupancy Rate
Average Daily Rate (ADR)
Revenue per Available Room (RevPAR)
Realization %
Booking Trends

#### Dashboard Features
Executive KPI Cards
Revenue Trend Analysis
Occupancy Analysis
Booking Platform Performance
City-wise Performance
Property-wise Analysis
Interactive Filters and Slicers
